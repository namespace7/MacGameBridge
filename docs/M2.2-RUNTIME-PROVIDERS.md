# M2.2 — Runtime Providers

## Goal

Introduce a provider-oriented runtime model that allows MacGameBridge to identify,
classify, and validate compatible runtime installations independently of their
distribution format.

Initial providers:

- **Wine** (standalone) — Homebrew, MacPorts, direct builds
- **CrossOver** (wrapper) — CodeWeavers bundle with bundled Wine engine
- **Whisky** (wrapper, legacy/deprecated) — discovery only
- **Sikarugir / Wineskin** (wrapper) — Wineskin-style wrappers

## Key concepts

### Provider classification

Each provider is either:

- **standalone**: A command-line executable installed directly into PATH
  (e.g., `wine64` from Homebrew). Discovered by scanning PATH directories.
- **wrapper**: An `.app` bundle that contains a Wine engine distribution
  (e.g., `CrossOver.app`). Discovered by scanning application directories
  for matching bundle name prefixes.

### Detection vs. validation

- **detected**: The bundle or executable was found on disk.
- **validated**: The wine executable was found, has the executable bit, and
  its Mach-O architecture was inspected successfully.
- **not_detected**: No matching installation found in the searched locations.

Validation never executes the binary. It uses `/usr/bin/file` to read the
Mach-O header.

## Architecture detection

Uses `/usr/bin/file -b <path>` which reads the Mach-O header without
executing the binary. Parsed output:

- `Mach-O 64-bit executable arm64` → `arm64`
- `Mach-O 64-bit executable x86_64` → `x86_64`
- `Mach-O universal binary with 2 architectures` → `universal`


## Limitations

- Discovery is intentionally shallow; it does not crawl the entire disk.
- It does not create or modify Wine prefixes or CrossOver bottles.
- It does not execute any runtime or game binary.
- It does not identify graphics translation layers.
- It does not infer DirectX, anti-cheat, DRM, or multiplayer compatibility.
- A runtime installed under an unsearched custom location may not be detected.
- Architecture inspection requires `/usr/bin/file` (always present on macOS).
