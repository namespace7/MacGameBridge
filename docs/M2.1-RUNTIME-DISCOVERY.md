# M2.1 — Runtime Discovery

## Goal

Discover known compatibility runtime app bundles and command-line executables without launching, installing, updating, or modifying them.

## Commands

```bash
swift run macgamebridge runtimes
swift run macgamebridge runtimes --json
swift run macgamebridge diagnostics
```

## Search scope

Application bundle discovery checks immediate `.app` children in:

- `/Applications`
- `~/Applications`
- `/Applications/Setapp`
- `~/Applications/Setapp`

The executable search checks names in the process `PATH`:

- Wine: `wine`, `wine64`
- Game Porting Toolkit: `gameportingtoolkit`, `gameportingtoolkit-no-hud`

CrossOver, Whisky, and Game Porting Toolkit app bundles are also searched by their known bundle-name prefixes.

`RuntimeDiscoveryPaths` is injectable so tests can use temporary directories without depending on what is installed on the developer's Mac.

## Status meaning

- `detected_unverified`: a matching app bundle directory or executable file was found. No runtime launch was attempted.
- `not_detected`: no match was found in the configured search locations. This does not prove that the runtime is absent elsewhere.

App bundle version metadata is read from `Contents/Info.plist` when available. CLI executable versions are deliberately not queried in this milestone because that would execute the runtime command.

CrossOver's bundled Wine executable is excluded from the standalone Wine finding when a PATH symlink resolves inside `CrossOver.app`.

## Explicit limitations

- Discovery is intentionally shallow; it does not crawl the entire disk.
- It does not inspect CrossOver bottles or Wine prefixes yet.
- It does not identify graphics translation layers yet.
- It does not launch applications or games.
- It does not infer DirectX, anti-cheat, DRM, or multiplayer compatibility.
- A runtime installed under an unsearched custom location may not be detected.

## Performance

Runtime discovery enumerates the immediate children of each configured application
directory and executable PATH directory synchronously. On the common case (local
SSDs, typical PATH length) this completes in milliseconds. Network mounts, very
large directories, or extensive PATH entries may increase latency.

No caching is performed. Every invocation re-scans the search roots.

These limitations are deliberate. M2.2 will add safe runtime metadata inspection;
later milestones will address bottles, graphics layers, and game-specific testing.
